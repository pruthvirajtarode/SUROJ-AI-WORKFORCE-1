# SUROJ BUILDCON × BE10X - AI Workforce Transformation

An interactive enterprise AI training and workforce transformation platform.

## Overview
This platform transforms the Eight-Session Batch Plan into a polished interactive web application designed for enterprise deployment. It serves as an AI transformation command center and interactive workshop operating system.

## Features
- **Dashboard & KPIs:** Live tracking of participants, sessions, and learning families.
- **Session Modules:** Detailed views for all 8 sessions, tailored for specific Suroj departments.
- **Interactive Labs:** Synthetic Data generator, AI Workflow builder, and Data Safety quiz.
- **Libraries:** Premium prompt library and case studies.
- **Trainer Dashboard:** Session timing, agenda tracking, and open placement questions.

## Tech Stack
- React 18
- Vite
- TypeScript
- Tailwind CSS v4
- Recharts
- Lucide Icons
- React Router

## Development
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Deployment
This project is configured for direct deployment to Vercel. A `vercel.json` is included to handle client-side routing.
